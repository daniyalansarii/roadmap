Framework vs Library

Many beginners get confused between frameworks and libraries. The easiest way to understand the difference is by knowing who controls the flow of the program.

What is a Library?

A library is a collection of pre-written code that developers can use to perform specific tasks more quickly and efficiently. You decide when and where to use the library in your application. In other words, your code calls the library whenever you need it.

Features of a Library

  • Provides reusable code.
  • Speeds up development.
  • Gives developers more flexibility.

Examples of Libraries

  1. React.js
  2. jQuery

What is a Framework?

A framework is a complete structure that provides predefined rules, architecture, and tools for building applications. Unlike a library, the framework controls the flow of the application. Your code fits into the framework's structure, meaning the framework calls your code when needed.

Features of a Framework

  • Provides a complete project structure.
  • Includes built-in tools and conventions.
  • Controls the application's flow.

Examples of Frameworks

  1. Angular
  2. Express.js

Library vs Framework

Library Framework
A collection of reusable code. A complete structure for building applications.
You control the program flow. The framework controls the program flow.
Your code calls the library. The framework calls your code.

4(a) What is Bootstrap ?

Bootstrap is a free, open-source CSS framework used to build responsive, mobile-first, and modern websites quickly and efficiently. It provides a collection of pre-designed components, a powerful grid system, and utility classes that help developers create attractive user interfaces without writing large amounts of CSS from scratch.

Key Features of Bootstrap

  • Mobile-first and responsive design.
  • Ready-to-use UI components.
  • Powerful 12-column grid system.

Common Bootstrap Components

  • Navigation Bars (Navbar)
  • Cards.
  • Forms
  • Tables

4(b) What is Tailwind CSS ?

Tailwind CSS is a free, open-source, utility-first CSS framework used to build modern, responsive, and highly customizable websites without writing large amounts of custom CSS. Instead of providing pre-designed components, Tailwind CSS offers a large collection of utility classes that allow developers to style elements directly in their HTML.

Key Features of Tailwind CSS

  • Utility-first approach for faster development.
  • Mobile-first and responsive design.
  • Highly customizable through a configuration file.

Common Tailwind CSS Utility Classes

  • Text Utilities
  • Background Utilities
  • Spacing Utilities
  • Flexbox Utilities

5(a) What is Git ?

Git is a free and open-source version control system created by Linus Torvalds in 2005. It records every change made to a project's files, allowing developers to view history, restore previous versions, create separate branches for new features, and merge changes safely.

Key Features of Git

  • Tracks changes in source code.
  • Maintains a complete project history.
  • Supports branching and merging.

Common Git Commands

  • git init
  • git add
  • git commit
  • git push

5(b) What is GitHub ?

GitHub is a cloud-based platform that allows developers to store, manage, and share Git repositories online. It provides tools for collaboration, code review, issue tracking, project management, and continuous integration, making it one of the most popular platforms for software development.

Key Features of GitHub

  • Cloud storage for Git repositories.
  • Team collaboration..
  • Project management tools.

Git vs GitHub

Git GitHub
A version control system. A cloud platform for hosting Git repositories.
Works locally on your computer. Works online through the internet.
Tracks changes in files. Stores and shares Git repositories.

6. What is React ?

React is a free, open-source JavaScript library used to build fast, interactive, and reusable user interfaces (UI) for web applications. It was developed by Meta (formerly Facebook) and is one of the most popular technologies for frontend development.React allows developers to build websites by dividing the user interface into small, reusable pieces called components. Each component manages its own content and behavior, making applications easier to develop, maintain, and scale.

Key Features of React

  • Component-based architecture.
  • Reusable UI components.
  • Fast rendering using the Virtual DOM.

Core Concepts of React

  • Components
  • JSX.
  • Props
  • Hooks
  • State

Popular Applications Built with React

What is Redux Toolkit ?

Redux Toolkit (RTK) is the official, recommended tool for writing Redux logic in modern React applications. It simplifies state management by reducing boilerplate code and providing built-in utilities for creating stores, reducers, actions, and asynchronous logic.Redux Toolkit makes it easier to manage and share application data (called state) across multiple React components. Instead of passing data through many components using props, Redux Toolkit stores the application's state in a centralized location called the Redux Store, making the data accessible from anywhere in the application

Key Features of Redux Toolkit

  • Simplifies Redux development.
  • Reduces boilerplate code.
  • Provides a centralized state management system.
  • Easy integration with React using React Redux.

Core Concepts of Redux Toolkit

  • Store
  • Slice
  • Reducer
  • Dispatch
  • Selector
