8. What is Express.js ?

9. What is MongoDB ?

MongoDB is a free, open-source, NoSQL database used to store, manage, and retrieve data for modern web applications. Unlike traditional relational databases that store data in rows and tables, MongoDB stores data in documents using a flexible JSON-like format called BSON (Binary JSON). This makes it easier to work with complex and changing data structures. MongoDB is designed to handle large amounts of data efficiently and is widely used in modern web development. It is a core part of the MERN Stack, where it works with MongoDB, Express.js, React, and Node.js to build full-stack web applications.

Key Features of MongoDB

10. What is REST APIs ?

REST API (Representational State Transfer Application Programming Interface) is a set of rules and standards that allows different software applications to communicate and exchange data over the internet. It enables a client (such as a web or mobile application) to send requests to a server and receive responses in a standard format, usually JSON. REST APIs are one of the most common ways for frontend and backend applications to communicate. For example, when you log in to a website, view products in an online store, or check the weather in an app, a REST API is used to send requests to the server and retrieve the required data.

Key Features of REST APIs

  • Enables communication between client and server.
  • Uses standard HTTP methods.
  • Transfers data in JSON format.

Common HTTP Methods

  • GET
  • POST
  • PUT
  • PATCH
  • DELETE

How REST APIs Work

  • The client (browser, React app, or mobile app) sends an HTTP request.
  • The server (Node.js + Express.js) receives the request.
  • The server processes the request and interacts with the database if needed.
  • The server sends a response, usually in JSON format.
  • The client displays the received data to the user.

11. What is Authentication (JWT) ?

Authentication is the process of verifying the identity of a user before allowing access to a website, application, or protected resources. It ensures that only authorized users can log in and perform specific actions, such as viewing personal information, making purchases, or accessing an admin dashboard. One of the most popular methods of authentication in modern web development is JWT (JSON Web Token). JWT is a secure and compact token-based authentication system that allows users to stay logged in without storing session data on the server. When a user logs in successfully, the server generates a JWT and sends it to the client. The client stores the token (typically in an HTTP-only cookie or secure storage) and sends it with future requests. The server verifies the token before granting access to protected resources.

What is JWT ?

JWT (JSON Web Token) is an open standard used to securely transmit information between a client and a server as a digitally signed token. It contains encoded user information and can be verified by the server to confirm the user's identity.

A JWT consists of three parts:

  • Header.
  • Payload.
  • Signature.

How JWT Authentication Works

  • The user enters their email and password.
  • The client sends the login request to the server.
  • The server verifies the user's credentials.
  • If the credentials are correct, the server generates a JWT.
  • The JWT is sent to the client.
  • The client stores the token securely.
  • For future requests, the client sends the JWT.
  • The server verifies the JWT before providing access to protected resources.

Key Features of JWT

  • Secure user authentication.
  • Stateless authentication (no server-side session storage).
  • Compact and lightweight.
  • Easy to use with REST APIs.
  • Can include user roles and permissions.

Common Uses of JWT

  • User login and registration.
  • Authorization based on user roles.
  • Protecting private API routes.

12. What is Deployment ?

Deployment is the process of making a website or web application available on the internet so that users can access it from anywhere in the world. After developing, testing, and debugging an application on a local computer, developers deploy it to a hosting platform or cloud server where it becomes publicly accessible. Deployment is the final stage of the software development process. It allows users to access your application through a domain name or a public URL instead of running it only on your local machine. In modern web development, developers commonly deploy frontend applications to platforms like Netlify and Vercel, while backend applications are deployed to services such as Render, Railway, or cloud providers like AWS, Google Cloud, and Microsoft Azure..

Key Features of Deployment

  • Makes applications accessible on the internet.
  • Publishes websites for real users.
  • Enables global access through a public URL..

Types of Deployment

Frontend Deployment

Frontend applications built with HTML, CSS, JavaScript, or React are commonly deployed on:

  • Netlify
  • Vercel
  • GitHub Pages
Backend Deployment

Backend applications built with Node.js and Express.js are commonly deployed on:

  • Render
  • Railway
  • AWS
Database Deployment

Databases can be hosted on cloud services such as:

  • MongoDB Atlas
  • PostgreSQL Cloud
  • MySQL Cloud
Deployment Process
  • Complete the application development.
  • Test and fix any bugs.
  • Push the project to GitHub.
  • Connect the GitHub repository to a hosting platform.
  • Configure environment variables if required.
  • Build and deploy the application.
  • Receive a live URL that anyone can access.
Why is Deployment Important?

Deployment allows developers to share their applications with users, clients, employers, and team members. It also enables real-world testing, continuous updates, and easier collaboration. A deployed application serves as a portfolio project that demonstrates your skills to recruiters and potential clients.
